HTMLを打ってみよう

前回の「ネオシ操作」ではNeocitiesのアカウントを作り、サイトURLを確保できました。
次は実際のコード打ちに移りますが、その前にHTMLコードの読み方を簡単に説明します。

HTMLは「タグ」と呼ばれるパーツでできていて、半角不等号の囲いが目印です。
また、ほとんどのタグは括弧のように範囲を示すので、閉じる位置には半角スラッシュを挟んだものを置きます。
例：<body>〜</body> <h1>〜</h1> <table>〜</table>

単体で使うタグ（閉じタグがなく、間に文字を挟めない物）もありますが、数はとても少ないです。
普段使いするものは全て本ページで紹介します。
ちなみに、上下の横線装飾にある<hr>もその一つです。

また、タグには「属性」といった設定のようなものを追加することもできます。
リンクを指定する<a>タグでは、<a href="(URL)">という形でリンク先を指定します。また、同じタグに複数の属性を追加することができます。

それでは、早速HTMLを打ってみましょう。

Neocitiesファイル一覧に入っているindex.htmlにカーソルをかざすと"Edit"（編集）ボタンが表示されるので、クリックしてファイルを開きます。

HTMLファイルの構造は<head>と<body>の2つの部分に分かれているので、片方ずつ見ていきましょう。

ページ設定 <head>

備え付けのファイルにはこのようなコードが入っています。
太字部分を除いたコードがページの内部設定になります。
上から1行ずつ、追加・変更推奨部分も合わせて紹介します。 

<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>The web site of ichikara-test</title>
    <!-- The style.css file allows you to change the look of your web pages.
         If you include the next line in all your web pages, they will all share the same look.
         This makes it easier to make new pages for your site. -->
    <link href="/style.css" rel="stylesheet" type="text/css" media="all">
  </head>
  <body>
    〜中略〜
  </body>
</html>
<!DOCTYPE html>
「これはHTMLファイルだからHTMLコードのルールに則って表示してね〜」というブラウザに対する指示。
必ず一番最初の行に置きます。閉じタグはありません。
<html> </html>
HTMLファイルの内容の全てを囲うタグ。
<!DOCTYPE html>以外のものは全てこのタグの中に入れます。
このタグにlang属性を追加すると、ページの言語が指定できます。視覚障害を持っている方が開いた時に正しい言語で読み上げられるようになるので、必ず入れるようにしましょう。
日本語の場合は<html lang="ja">、英語の場合は"en-US"や"en-GB"と記入してください。言語の一部リストはこちら。
<head> </head>
<html>の中に入る大きな2区分のうちの1つ。
ブラウザ用の設定などを囲うタグ。ページを開いた時にはブラウザの画面に表示されません。
<meta charset="UTF-8">
文字化けを防ぎます。<head>内の一番最初に入っていると安全です。
ちなみに<meta>タグは全て閉じタグ不要です。
<meta name="viewport" content="width=device-width, initial-scale=1.0">
デバイスごとに表示がいい感じに調整されます。
これが無いとスマホで文字がちっちゃ〜くなったり、PCで特大になったりしてしまいます。
<title> </title>
ページのタイトル。
ブラウザのタブに表示される部分なので、トップページの場合はサイトの名前、その他のページの場合は内容の見出しなどを入れるといいです。
<!-- -->
メモを指定するタグ。<head>内だけではなく、HTMLファイルのどの部分にも入れることができ、これで囲った内容はブラウザに全て無視されます。
管理人は「ここ更新したらメニューの更新履歴も書くこと！」などといった自分に向けたリマインダーを入れることが多いです。
Neocitiesのファイルにはstyle.cssのメモが入っていますね。これは次回の記事③で解説するので、このメモは消しても何も問題ありません。
<link href="/style.css" rel="stylesheet" type="text/css" media="all">
前回の記事で紹介した、「ページの見た目を変えられる便利グッズ」のCSSファイルをこのタグで呼び出します。これも閉じタグはありません。
使い方は後ほど解説するのでこの<link>はこのまま置いておきましょう。

必須ではないが知っておくといいタグ：

<meta name="robots" content="noindex, nofollow">
検索避け用のタグ。GoogleやYahooなどのサーチエンジンにページが（なるべく）表示されなくなります。
二次創作などの同人活動をする方はこれをrobots.txtと合わせて使うことを強く推奨します。詳しくはこちらのサイトをご覧ください。本講座でも後ほど解説を用意します。

ここで紹介した内容と検索避けを合わせると、</head>まではこのようなコードになります。 

<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="robots" content="noindex, nofollow">
    <title>ページのタイトル</title>
    <link href="/style.css" rel="stylesheet" type="text/css" media="all">
  </head>

検索避けに関しては、導入するページとしないページを分ける使い方（トップページ以外の全ページに導入したり、サイトの中でも同人活動をしているページにのみ導入するなど）もあります。
上記のコードはそのままコピペでOK。変更部分は検索避けを導入するかどうかとページタイトルのみで、他は基本的に全ページ共通です。

ページ内容 <body>

自動作成ファイルの続きを見てみましょう。
ここからがブラウザで開いた時に表示される内容を指定するコードです。

編集画面で"Save"（保存）してから"View"（開く）をクリックするとページが別窓で表示され、いつでも見た目を確認できます。
Viewボタンが表示されていない時（スマホなど）はページ一覧からファイル名をクリックすると開けます。
※変換が反映されない場合は Ctrl/⌘ + Shift + R（強制ページ更新）してみてください。 

  <body>
    <h1>Welcome to my Website!</h1>

    <p>This is a paragraph! Here's how you make a link: <a href="https://neocities.org">Neocities</a>.</p>

    <p>Here's how you can make <strong>bold</strong> and <em>italic</em> text.</p>

    <p>Here's how you can add an image:</p>
    <img src="/neocities.png" alt="Site hosted by Neocities">

    <p>Here's how to make a list:</p>

    <ul>
      <li>First thing</li>
      <li>Second thing</li>
      <li>Third thing</li>
    </ul>

    <p>To learn more HTML/CSS, check out these <a href="https://neocities.org/tutorials">tutorials</a>!</p>
  </body>
</html>

最後に</html>を閉じることを忘れずに！
